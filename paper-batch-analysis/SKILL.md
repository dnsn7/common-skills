# 论文批量分析

分析指定文件夹下的全部论文，也支持单篇论文或论文清单，生成有出处、通俗、可比较的中文 Markdown 报告。调用本技能时默认生成 MD 文件；用户明确要求只在聊天窗口输出时遵从该要求。Markdown 使用新编号文件，不覆盖既有结果；不主动制作 PPT 或扩展研究选题。

## 输入与批次处理

- 主要接收文件夹路径，默认递归扫描其下可识别的论文文件，通常为 PDF；也接收单篇 PDF、DOI、论文标题、链接或已有论文清单。先理解目录结构，用文件清单定位材料，不修改原始论文。补充材料关联到主论文，已有分析报告、代码文档和非论文文件不算独立论文；识别不清的文件列为待确认，不静默遗漏。
- 保持用户顺序和编号；文件夹输入未指定顺序时按相对路径自然排序并固定编号。去重时说明原文件与分析条目的对应关系。不同版本、预印本与正式发表版本先辨认，避免误合并。
- 操作前一次性询问确实影响全局且无法推断的信息，如歧义标题指向哪篇论文、缺失的附件。用户示例足以确定格式时直接执行。默认不限制发表年份、研究方向或期刊等级，不另行扩展选题。
- 先整理输入清单，逐篇标记全文、补充材料、官方代码、发表信息的获取状态。不能获取某篇全文时继续分析其他篇，并将该篇明确标为“仅依据摘要/现有材料的有限分析”。批量过长可分批处理，最终报告覆盖整批，保留编号并交代未完成条目，不以一篇代替整批。空目录或无可识别论文时如实报告，不编造条目。

## Markdown 保存与交付

- 默认一批生成一份汇总 MD，包含扫描范围、分析日期、论文清单（编号、原文件、完整标题、处理状态）、按下述固定结构排列的逐篇分析和引用来源。单篇也生成一份 MD，使用相同逐篇结构。只有用户要求时才拆成每篇一个文件。
- 文件夹输入默认保存到该文件夹根目录；单篇文件输入保存到文件所在目录；只有标题、DOI或链接时保存到当前工作目录。用户指定输出位置时优先采用。
- 批量文件名使用 `01_论文批量分析.md`，单篇使用 `01_论文分析_短标题.md`。先检查输出目录已有数字前缀，取最大编号加一（无则从01开始，至少两位），并检查目标路径不存在。新版本同样使用新编号，不覆盖旧报告。固定入口 `SKILL.md` 属技能配置，不属于论文报告的编号规则。
- 保存为 UTF-8；使用真实的 Markdown 标题层级分隔论文，保留方法箭头流程、关键事实旁的引用和原文件对应关系。不得用未分析条目的占位文本冒充整批完成。
- 保存后重新读取报告，检查编码、论文覆盖数量、重复或遗漏、编号、链接及每篇栏目完整性。聊天窗口先说明完成结果和未完成限制，再提供报告的绝对路径链接，不重复粘贴整份报告。

## 证据获取与核验

1. 确认完整标题、DOI、年份、版本及正式发表渠道，优先出版社页面、正式全文、补充材料和作者官方仓库。检索结果摘要只用于定位；无法读到全文不能宣称完成全文核查。
2. 影响因子必须联网核实并注明 JIF 数据年份及来源，例如“2024 JIF：X（来源……）”。优先 Clarivate/JCR 或明确注明年份的期刊官方页面；不可把 CiteScore、分区或第三方估计冒充 JIF。无法可靠确认写“未可靠核实”。会议及预印本写“不适用期刊影响因子”；预印本不能当成已正式发表。不默认加分区，用户要求时另外查体系和年份。
3. 为关键事实保留内部证据记录：来源、页码/章节/表号、对应人群或实验设置、原始数值。交付时在相应句旁放可访问的来源链接；本地 PDF 用可点击文件链接并注明页码或表号。使用编号引用时必须提供编号到来源的映射，不能复制示例的“[7]”而没有来源。
4. 分开处理论文事实、作者解释与本次分析。信息在可访问全文中没有报告写“本文未提及”；未取得或未检查相应材料写“本次未确认”，不能混用。外推明确标“分析判断”或“领域经验推测，非论文原文”。

## 每篇固定输出

采用以下顺序，使用短段落；术语首次出现解释中文含义。每栏都保留，未知项如实标注。具体长度随复杂度调整，方法和重要纠偏优先保证清楚。

论文N：概括该篇技术重点的中文短标题；材料不足以概括时沿用原题并标注“技术重点本次未确认”。

**完整标题：** 原始完整标题。

**发表渠道与影响因子。** 期刊/会议/预印本平台、发表年份与状态、DOI或官方链接；期刊 JIF 的数值、数据年份和核实来源。正式年份与在线先行年份不同则说明。

**为了解决什么问题？** 先用具体场景解释“现有方法在哪种情况下遇到什么困难，造成什么影响”，再说明本文目标。不能只写“提高准确率”；没有原文支持的临床效果或机制不作事实陈述。

**怎么做？** 用 `输入 → 关键处理 → 模型/判断 → 汇总输出 → 验证或下一去向` 写出真实流程，再解释核心步骤的输入、处理、输出及输出去哪。材料不足时只列已知步骤，明确缺失环节；顺序未确认时不用箭头暗示先后关系。训练和推理有区别时分别说明。涉及多个评分、损失或分支时逐个解释其含义；比例评分明确分子、分母及统计层级，必要时说明对肿瘤量、组织量或取材大小的不同敏感性。

**数据与效果。** 写来源、时间范围、任务标签、样本数量及单位、患者数（若报告）、划分方式、内部/外部验证和主要指标。选择能回答研究问题的结果，不只报最高值；数字对应具体队列、方法、评分和设置。置信区间、阈值和样本不平衡在影响解释时说明。范围只用于可解释的同类设置，并说清来源。

**这篇的价值。** 解释它带来哪项实际方法认识、稳健性证据或应用可能，以及证据覆盖到哪里。不能把年份更新、模块堆叠或作者自称创新直接当成实质进步；临床决策价值与离线预测指标分开。

**重要纠偏、与相似论文的区别或更新。** 对照最相关的已有条目或原文参照研究，指出任务、输入、处理、评分分母、验证队列和结果的实质区别。清晰区分“作者明确声明的延续/改进”“有证据的流程相似”和“尚未确认的关系”。没有明显误读时也写关键证据边界，不制造错误来纠正。

**复现状况与公开代码。** 分别交代数据是否公共、是否含所需模态与标签，代码是否官方及可访问，仓库是否提供训练/推理/预处理、权重、依赖和划分等关键资源。给链接和本次检查范围。按证据说明“资源较完整但未运行验证”“可做部分复现”“关键资源缺失”或“本次未确认”，不能保证完全复现。

## 容易误读的边界

| 易错点 | 正确处理 |
|---|---|
| 标本数、WSI数或patch数当作独立患者数 | 保留原始单位；一人多标本或多切片不推断成独立患者，患者数未报告则明说 |
| 内部和外部 AUC 混成最高性能 | 标注数据集与设置；AUC 为 ROC 曲线下面积，数值不能跨不同人群直接排名 |
| 一种评分胜出写成全面领先 | 检查各评分及对照；部分设置落后必须指出，不能把数值差异直接写成统计显著 |
| 流程相似或引用某篇论文当作直接继承 | 核查作者声明、方法差异与引用语境；单纯相似或引用不足以证明继承 |
| 合理请求获取等于公开数据集 | 明确请求获取的限制；公共外部子队列不能代替整套临床训练数据 |
| 仓库存在等于完整可运行 | 核查实际文件范围；README、演示、推理脚本与完整训练流水线分开 |
| 没找到代码等于没有代码 | 写“截至本次检索未确认官方代码”，不能作绝对不存在判断 |

## 输出前评估

检查扫描清单中的全部论文都有对应分析或明确的未完成原因，补充材料及去重映射可追溯；报告已保存到约定位置且未覆盖旧文件；编号和引用可追溯；每个数字的样本单位、队列和设置相符；JIF 有数据年份；流程与全文一致；相似性没有写成继承；公开数据和请求获取分开；代码完整性与实际运行验证分开。检索或资源不足时明确剩余未知，不用推测补齐。

用户要求横向总结时，在逐篇结果后补简短比较表；没有要求则不要让跨篇总结替代每篇分析。
