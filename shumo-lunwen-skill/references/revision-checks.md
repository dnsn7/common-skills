# 论文整改检查点：仅供款式与避错参考

本页提炼多轮论文修订中反复提出的整改要求。用于新题时重新核对题目、代码、结果和当届赛规；旧稿内容不进入新论文。

## 认可的论文叙述路线

- 先建立整篇结构，再确定每一节/段的职责、公式与图表放置、结果指标和排版。
- 逐问按“问题分析→数据处理→模型与求解→结果检验→本问结论”展开；内部写成“输入→处理→输出→下一去向”。
- 模型段围绕“为什么需要它、用了什么输入、怎样处理/求解、产出了什么、效果如何、支持下一问什么”展开。后续段落语言精简、连贯，保持足够的建模过程细节。
- 结果先作答，再报数值和对照；末尾总结用途及局限。摘要与正文逐问一致。

## 具体整改记录与未来检查点

| 曾出现的问题或用户要求 | 未来处理 |
|---|---|
| “主要体现目的、效果、好处”“建模比赛突出模型” | 写明模型目标、变量、约束、求解、验证及效果来源；不以美化代替建模。 |
| “全文流程自然，表达可以高中生一些” | 首次定义术语，用小例子解释关键机制；每一步说清输入、输出和去向。 |
| 公式单独一行、右侧序号、交叉引用 | 使用可编辑公式与自动编号/引用，核对引用可解析。 |
| 表格统一三线表 | 全文采用一致三线表，表题在上，避免表头与数据断页。 |
| 无页眉身份信息、摘要页开始页码、居中页脚等 | 作为当次格式硬检查；新比赛先看官方模板。 |
| 图多但读不懂 | 每图写出图义、读法、直接结论、作答作用和证据边界。 |
| 旧版内容混入新稿 | 按标题与来源识别版本，不以固定段落位置截取，不合并互不相容的模型或指标。 |
| 结果来源混称 | 分开真实数据、拟合、半合成、校准、插值、预测和外推；不把保存表述为本次运行。 |
| 问题尚未写完 | 预留位置并清楚标出；不补虚构内容。 |
| Word 文本/XML 看起来正确但排版有问题 | 更新域并逐页渲染，查公式裁切、题注分离、空白页、页码和图片清晰度。 |
